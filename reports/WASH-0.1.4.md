# Album Builder — Wash 0.1.4

> Post-delivery correction: 0.1.4 introduced a production worker-packaging regression that development-server tests did not detect. It is repaired and verified against both production files and the native app in [the 0.1.5 fix report](AUDIO-WORKER-FIX-0.1.5.md). The historical checks below should not be read as successful packaged audio-analysis acceptance.

Audit date: **29 October 2026 (Australia/Sydney)**. Baseline: 0.1.3. Scope: the whole first-party macOS product, preserving the existing visual language, licensing policy, audio sources and earlier user edits.

This report records concrete defects and their repairs. It does not claim that every possible bug has been eliminated. Synthetic fixtures and disposable browser profiles were used throughout. No personal media was modified, no live licence was activated/deactivated, and no publication or distribution was performed.

## Remaining acceptance limits

Native screen capture failed in the preceding 0.1.3 run with ScreenCaptureKit -3811 / -10005; capture and accessibility inspection succeeded for 0.1.4. The current native smoke check inspected the empty Night workspace, opened/returned from Release Copy, checked About version/privacy content, closed it with Escape and quit an unchanged empty session with Cmd-Q. This does not establish native Quit while a save is pending, responsiveness under network/export load, live licence/network behavior, real external-drive restoration, audio hardware/device switching, or physical listening quality. Those remain explicit acceptance gaps, not silently passed checks.

The browser preview intentionally cannot restore source audio after a page reload; attempts now fail clearly and retain the saved record. Durable audio sessions use the desktop app. Transition Layout remains a preview: Export Album writes ordered source copies rather than rendering a mixed transition master. No feature removal, framework replacement, personal-file cleanup, live-account changes, publication or distribution was part of this Wash.
